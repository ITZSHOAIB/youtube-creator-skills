# Content-Pillar Calendar

Use when the creator wants a batch of future video ideas or a monthly plan. Read channel memory and performance reviews first.

## Build the matrix

Choose 3–5 approved content pillars and pair them with relevant YouTube formats:

- Hands-on review
- Buyer guide / verdict
- Comparison
- Problem / fix
- Feature explainer
- Myth / mistake
- Timely update
- Search-led tutorial

For each useful cell, write a specific video concept, target viewer problem, discovery route, proof needed, and production effort. Do not fill cells merely to complete a grid.

## Prioritize

Select a small practical slate using current demand, channel fit, creator access, portfolio balance, shelf life, and production capacity. Label assumptions and preserve the creator's final control over what gets made.
