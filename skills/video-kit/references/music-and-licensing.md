# Music recommendations and licensing

Read only when music direction or track recommendations are requested or channel memory calls for them. Verify current track and license details before recommending a specific recording.

- Follow channel memory on whether to add music cues or recommend tracks. When recommending, use YouTube Studio Audio Library or Pixabay and verify the exact entry's current license, attribution, monetization terms, and Content ID/claim information where available. Prefer tracks without attribution; record the source and checked date. Do not trust generic “no copyright” claims or promise third-party tracks are claim-free. See [Pixabay's license](https://pixabay.com/service/license-summary/) and [Content ID FAQ](https://pixabay.com/service/faq/).
- Follow the creator's saved attribution preference. If credits are required, offer the requested number of verified options when available, then use the exact required credit only after the creator chooses. Never invent a track, license status, or credit wording. Keep the publishing package usable while a music choice is pending.
- Add useful edit/music cues when they help the video. Do not generate music by default. If requested, verify the generation tool and model licenses for the intended monetized use and save that evidence with the project.
