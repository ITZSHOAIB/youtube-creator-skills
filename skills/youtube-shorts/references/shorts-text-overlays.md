# Text-Overlay System

Use this guide only when a Short needs designed text, labels, diagrams, or a CTA. Treat overlays as part of the edit, not captions pasted over footage.

## Visual-direction checkpoint

Read the brand kit, prior approved Shorts, and the current creator brief first. Do not ask for preferences that are already established.

Ask at most two compact questions before mockups when visual direction is unclear and the answer would materially change the result:

1. **Design direction:** clean product, punchy branded, editorial, playful, or match a supplied reference.
2. **Energy and information level:** minimal and calm, balanced, or high-energy; then confirm whether functional graphics such as icons, diagrams, counters, or a progress marker should be used.

Motion defaults to polished and restrained unless the creator requests otherwise. Ask a third question only if there is a real choice about preserving an existing edit, a special transition style, or an intentional departure from the brand kit.

Record the selected direction, density, motion, graphic elements, and exclusions in the Short brief. Apply them to every scene. Do not reopen these choices during normal refinement unless the creator changes direction.

## Default decisions

When no conflicting preference exists, apply these decisions without asking:

- Read the channel brand kit for fonts, palette, logo rules, and existing visual language.
- Use one main headline, with only the support detail needed to understand it.
- Keep natural footage and its approved edit intact; use modest color correction only for readability and consistency.
- Keep headline tracking slightly tight but readable. Do not use extreme letter spacing.
- Put the highest-priority information in the central safe area; maintain clear margins from platform UI.
- Use contrast, soft shadow, and a barely visible high-blur backing only where the footage needs it.
- Keep supporting labels, headers, and logo treatment consistent across related scenes.
- Use no diagram when a label or footage alone explains the point. Never duplicate an explanation in text and graphic form.
- Ensure all product, person, and logo imagery stays proportionate and natural-looking.
- Finish with an end-card layout that is related to the sequence but distinct enough to read as an ending.

## Build each scene

For every overlay beat, define:

1. **Job** — hook, specification, proof, qualifier, transition, or CTA.
2. **Primary line** — one short idea readable at phone size.
3. **Supporting detail** — only when it adds information not already visible or spoken.
4. **Proof visual** — the b-roll, icon, diagram, or label that supports the statement.
5. **Entrance and exit** — timed to the narration or edit, with no animation competing with speech.

Avoid duplicate copy. Do not restate the exact same price, feature, or claim in a headline and a support label on the same screen.

## Visual hierarchy

- Use the channel's primary headline font and weights for key phrases; use its supporting font only for small labels and qualifiers.
- Use one visual anchor per scene. A large headline, metric, or diagram should win attention before all secondary elements.
- Keep primary copy short: usually two to five words. Break longer information into beats.
- Use brand color as emphasis, not decoration. Keep most copy high-contrast neutral, then reserve accent colors for a number, keyword, or active indicator.
- Apply a very soft, almost invisible text backing or high-blur shadow only when footage needs help with legibility. Never use a visible opaque rectangle unless it is an intentional graphic card.
- Keep the logo compact and undistorted. It should identify the channel without becoming the main subject.
- Reuse a header or progress convention only when it provides continuity. Do not add an unrelated label such as “End card.”

## Safe layout for vertical video

- Keep essential copy in the middle of the 9:16 frame.
- Leave generous top space for platform labels and bottom space for captions, descriptions, and interactions.
- Leave the right edge clear for YouTube and Instagram controls.
- Check every scene at phone-sized playback before approval.

## Motion and graphics

- Animate for hierarchy: primary text arrives first, support text next, then a small proof graphic if useful.
- Use simple entrance motion: a short fade, upward reveal, scale settle, or masked wipe. Match one motion family through the Short.
- Let diagrams demonstrate the claim: a trigger travel indicator for analog pressure, a changing meter for polling rate, or a connection icon sequence for modes.
- Make transitions distinct only when they match the scene change. Sync a light transition sound to the visual beat, positioned in gaps so it does not cover narration.
- Use a progress marker or numbered header only when it helps viewers track a multi-beat feature sequence.

## Prototype review

Create one frame snapshot per overlay scene when a visual prototype or review is part of the requested work. Use snapshots to catch clip, crop, hierarchy, spacing, color, diagram, logo, and CTA issues before a requested final render. If a scene has too much copy, remove information before changing the type size.
