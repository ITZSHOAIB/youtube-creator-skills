# Reference Short Analysis

Use only when the creator supplies a reference Short/Reel or asks to study a proven example. The goal is to learn transferable structure, never to reproduce the source.

## Analyse

- First visual frame and first spoken words
- Hook duration and promise
- Beat timings, information density, and visual changes
- Spoken rhythm, sentence length, and use of proof
- Overlay hierarchy, diagram use, and CTA mechanics
- What is distinctive to the creator versus generally reusable

Record the source URL, access method, duration, and any limits. Do not call it an outlier without comparable performance evidence.

## Deliver

Give a concise pattern report followed by 2–3 original concept directions for the active channel. Each direction must use the creator's own evidence, voice, brand kit, and footage plan. The creator selects one before scripting.
