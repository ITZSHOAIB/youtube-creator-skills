# Adaptive Short Intake

Start from context. Read the matching video project, review brief, channel memory, brand kit, footage inventory, and prior creator decisions when available. Ask only for missing decisions that change the requested result.

Ask one concise question per turn when clarification is useful. Do not run an intake interview when the user has already specified the goal and deliverable.

## Decision order

1. **Outcome** — reach, clicks to a full video, search discovery, buyer guidance, followers, or a brand deliverable.
2. **Format** — feature teaser, lived-experience review, verdict, comparison, problem/solution, tutorial, opinion, or highlight cutdown.
3. **Reveal** — name it immediately, reveal later, conceal it for curiosity, or make the Short self-contained.
4. **Evidence** — manufacturer facts, creator experience, or both.
5. **Delivery** — script only, prototype, or rendered video.

Ask for platform, language, duration, available narration, b-roll, and non-negotiable claims only if they remain unknown after the source review.

## Format routing

| Format | Best for | Opening pattern | Ending |
| --- | --- | --- | --- |
| Feature teaser | Curiosity and long-video clicks | Unexpected feature or price tension | Name/reveal or full-video CTA |
| Experience review | Trust | Result after real use | Clear caveat or recommendation |
| Verdict | Buying intent | The buying question | Direct answer and buyer fit |
| Comparison | Choice | A meaningful tradeoff | Who should choose each option |
| Problem/solution | Broad relevance | Familiar friction | Demonstrated answer |
| Tutorial | Value and saves | Desired outcome | Complete actionable result |
| Highlight cutdown | Existing strong footage | Most compelling source moment | A complete thought and optional CTA |

## Reveal strategy

Curiosity helps only when the source can satisfy it. If the product stays unnamed, make the feature, price band, and visual proof specific enough to be credible. For search-first Shorts, use the actual name in spoken copy, text, title, description, and tags. If the creator deliberately conceals the name, preserve that choice in all public-facing copy unless they approve a different metadata strategy.
