# Creator Voice

Create one approved voice profile that every creator skill can read. It captures real patterns, not an invented persona.

## Workflow

1. **Load channel context.** Read `CHANNEL_MEMORY.md`, the brand kit, and existing `CREATOR_VOICE.md` when available. Reuse approved details; do not overwrite them from a small or contradictory sample.
2. **Collect representative evidence.** Ask for 3–5 samples only when the workspace does not already contain enough material. Prefer a mix of spoken transcripts and creator-written material. Label each sample's source and whether it represents spoken or written voice.
3. **Analyse patterns.** Identify language/register, sentence rhythm, code-switching, hook and transition habits, technical-explanation style, humour, CTA style, recurring phrases, and observed avoidance patterns. Separate explicit creator rules from tentative observations.
4. **Present a draft profile.** Show the concise profile and the evidence behind meaningful rules. Ask for corrections before saving it.
5. **Save only after approval.** Create or update `CREATOR_VOICE.md` in the channel workspace. Date the change and preserve unrelated confirmed rules.

## Evidence rules

- Never infer a first-person experience, product opinion, sponsorship stance, or identity from style.
- Absence in a few samples is a provisional observation, never an automatic ban.
- Do not force a universal English variant, jargon level, or script. Use the channel's approved publishing language and natural code-switching.
- Consumer skills should read the profile when it exists, but a source script or creator instruction always wins when they conflict.
