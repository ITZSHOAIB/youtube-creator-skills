# Social Repurpose

Extract distinct viewer value from an approved source. Do not mechanically resize or restate the main video.

## Workflow

1. **Load source and channel context.** Read `CHANNEL_MEMORY.md`, `CREATOR_VOICE.md` if present, the brand kit, parent script/review brief, publishing package, and available assets.
2. **Map reusable angles.** Identify the strongest self-contained moments: a useful verdict, a feature tease, a buyer warning, a comparison, a tutorial step, a myth, or a visual demonstration. Exclude claims that need unsupported context.
3. **Present the repurpose plan.** Recommend only the assets that serve a clear platform and goal. Include the source moment, unique promise, format, production effort, and link path back to the main video where appropriate.
4. **Wait for selection.** Do not create assets, edit video, generate graphics, or produce prompts until the creator approves selected items.
5. **Route production.** Use `youtube-shorts` for Shorts/Reels, `youtube-thumbnail` for cover thumbnails, and Video Kit for additional YouTube packaging. Keep platform-specific copy and source notes with each output.
6. **Save the plan.** Store `repurpose-plan.md` in the parent video project and link delivered assets.

## Rules

- One source video does not need every possible derivative format.
- Each selected asset needs a distinct hook and viewer benefit; avoid duplicate clips with only different captions.
- Preserve the creator's reveal strategy, disclosure requirements, and claim qualifiers.
- Never publish or cross-post without explicit creator authorization.
